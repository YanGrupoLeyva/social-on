# SOCIAL-ON

Panel interno de inteligencia digital del Grupo Leyva.

## Alcance de la primera versión

- Resumen ejecutivo de salud digital.
- Analítica de redes sociales por empresa y plataforma.
- Detalle interactivo de seguidores, publicaciones, alcance, engagement y demografía.
- Acceso directo a webs y perfiles sociales.
- Análisis de contenidos.
- Salud web, SEO, tráfico y conversiones.
- Lectura de publicidad y ROAS.
- Objetivos y alertas.
- Informes para dirección.
- Asistente virtual para generar resúmenes.

## Empresas iniciales

- LINMANIA
- ROCKSTAR
- LA MECA DEL MONEDERO
- LEYVA
- CONTACT-ON

> Los datos mostrados en esta versión son demostrativos hasta completar las integraciones con las APIs oficiales.

## Uso local

Abre `index.html` directamente en un navegador. El proyecto no necesita instalación ni compilación.
